# ADR運用

## 目的

長期的な設計判断を、理由、代替案、強制方法とともに残します。

## 状態

- `proposed`
- `accepted`
- `superseded`

`accepted` ADRの意味を直接書き換えず、新しいADRで置き換えます。

## 必須項目

```text
背景
決定
理由
検討した代替案
結果
強制方法
検証
```
